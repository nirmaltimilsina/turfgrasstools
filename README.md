# Turfgrass Decision Support Tools

Public website: https://nirmaltimilsina.github.io/turfgrasstools/

Interactive calculator: https://turf-pgr-gdd.streamlit.app/

This public website provides a directory of turfgrass management tools.
The available PGR growing degree day (GDD) calculator supports planning
plant growth regulator applications. The website explains how to use it
and links to the related research.

Developed independently by Nirmal Timilsina, Ph.D. candidate in Crop Science
at North Carolina State University.

Only website files are stored in this public repository. Python application
code is maintained separately in a private repository. Research-based
reapplication intervals are displayed only when published evidence is
available. Calculated dates are decision aids and do not replace product
labels or evaluation of turfgrass conditions.
