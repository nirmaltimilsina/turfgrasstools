# Turfgrass PGR GDD Calculator

Public website: https://nirmaltimilsina.github.io/turfgrass-pgr-gdd/

Interactive calculator: https://turf-pgr-gdd.streamlit.app/

This site introduces a growing degree day (GDD) calculator for planning
plant growth regulator (PGR) applications in turfgrass. It links to the
interactive calculator, explains its use, and provides research references.

Developed by Nirmal Timilsina, North Carolina State University.

The website files here are public. The Python application is maintained
separately. Research-based reapplication intervals are displayed only when
published evidence is available. Calculated dates are decision aids and
do not replace product labels or evaluation of turfgrass conditions.
