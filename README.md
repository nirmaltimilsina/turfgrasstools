# Turfgrass Tools

Public website: https://nirmaltimilsina.github.io/turfgrasstools/

Available PGR calculator: https://turf-pgr-gdd.streamlit.app/

This website is a directory of turfgrass calculators and field-data tools.
Each entry links to an independently maintained application when available.
Research methods, limitations, and citations belong in the individual apps.

Developed independently by Nirmal Timilsina, Ph.D. candidate in Crop Science
at North Carolina State University.

Only website files are stored in this public repository. Python application
code is maintained separately in private repositories.
